모델: Gemini 3.1 Flash-Lite (고정) · 설정과 요약 기록은 이 브라우저에만 저장됩니다.
처음 설정 방법
  1. Google Cloud Console에서 프로젝트를 만들고 YouTube Data API v3를 사용 설정합니다.
  2. OAuth 동의 화면: 사용자 유형 "외부", 테스트 사용자에 본인 Gmail 추가.
  3. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션. "승인된 JavaScript 원본"에 이 페이지 주소를 넣습니다. 예: https://아이디.github.io, http://localhost:8000
  4. Google AI Studio에서 Gemini API 키를 발급합니다.
  5. 위 칸에 클라이언트 ID와 API 키를 넣고 저장 → Google 로그인.

파일을 더블클릭해서 여는 방식(file://)은 Google 로그인이 안 됩니다. GitHub Pages에 올리거나, 이 파일이 있는 폴더에서 python -m http.server 8000 실행 후 http://localhost:8000으로 여세요.

설정을 마치고 Google 로그인을 해주세요.
